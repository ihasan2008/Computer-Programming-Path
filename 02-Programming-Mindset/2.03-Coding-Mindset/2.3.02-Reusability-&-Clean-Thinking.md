# > Reusability & Clean Thinking

Reusability & Clean Thinking হলো এমন একটি চিন্তাভাবনার পদ্ধতি, যেখানে কোনো Code, Design, System বা Solution এমনভাবে তৈরি করা হয় যাতে সেটি **পরিষ্কার (Clean), পুনঃব্যবহারযোগ্য (Reusable), রক্ষণাবেক্ষণযোগ্য (Maintainable), সম্প্রসারণযোগ্য (Scalable) এবং দীর্ঘমেয়াদে কার্যকর (Long-Term Effective)** হয়।

সহজ ভাষায়:

**একবার ভালোভাবে তৈরি করো, তারপর সেটি বারবার ব্যবহার করতে পারো—এই মানসিকতাই হলো Reusability & Clean Thinking।**

---

## What is Reusability?

**Reusability** হলো এমনভাবে কোনো Code, Component, Function, Module বা Design তৈরি করা, যাতে সেটি একই বা ভিন্ন Project-এ বারবার ব্যবহার করা যায়।

উদাহরণ:

একটি **Button Component** যদি একবার তৈরি করা হয়, তাহলে সেটি Website-এর বিভিন্ন Page-এ ব্যবহার করা যায়।

```text id="rct01"
Create Once
     |
Reuse Many Times
```

---

## What is Clean Thinking?

**Clean Thinking** হলো কোনো কাজ, Design বা Code শুরু করার আগেই এমনভাবে পরিকল্পনা করা, যাতে অপ্রয়োজনীয় জটিলতা না থাকে এবং ভবিষ্যতে সহজে পরিবর্তন, রক্ষণাবেক্ষণ ও উন্নয়ন করা যায়।

```text id="rct02"
Think Clearly
      |
Plan
      |
Build Cleanly
```

## What is Reusability & Clean Thinking?

Reusability & Clean Thinking হলো এমন একটি Software Development Mindset, যেখানে **একই সমস্যার জন্য বারবার নতুন সমাধান না লিখে**, একটি পরিষ্কার, মানসম্মত এবং পুনঃব্যবহারযোগ্য সমাধান তৈরি করা হয়।

* Software-এর Quality বৃদ্ধি পায়।

## Principles of Reusability

### 1. DRY (Don't Repeat Yourself)

একই Logic বারবার লিখবেন না।

❌

একই Function ৫ বার লেখা।

✅

একটি Function লিখে বারবার ব্যবহার করা।

---

### 2. Modular Design

বড় Project-কে ছোট Module-এ ভাগ করুন।

```text id="rct06"
Project
|
├── Authentication
├── Users
├── Products
├── Orders
└── Payments
```

---

### 3. Reusable Components

একটি Component বিভিন্ন জায়গায় ব্যবহার করুন।

উদাহরণ:

```text id="rct07"
Button
|
├── Home
├── Login
├── Contact
└── Checkout
```

---

### 4. Single Responsibility Principle (SRP)

প্রতিটি Function বা Module-এর একটি নির্দিষ্ট দায়িত্ব থাকা উচিত।

---

### 5. Consistent Naming

অর্থপূর্ণ এবং একই Style-এর Naming ব্যবহার করুন।

উদাহরণ:

```text id="rct08"
getUser()

createOrder()

calculateTotal()
```

## Difference Between Reusability and Clean Code

| Reusability                              | Clean Code                                     |
| ---------------------------------------- | ---------------------------------------------- |
| একই Code বা Component বারবার ব্যবহার করা | Code-কে সহজ, পরিষ্কার ও রক্ষণাবেক্ষণযোগ্য রাখা |
| পুনঃব্যবহার (Reuse)-এর ওপর গুরুত্ব       | Readability ও Maintainability-এর ওপর গুরুত্ব   |
| Development Time কমায়                   | Code বোঝা ও পরিবর্তন করা সহজ করে               |
| Component ও Module-কেন্দ্রিক             | Code Style ও Structure-কেন্দ্রিক               |

> **মনে রাখুন:** Clean Code থাকলে Reusability বাড়ে, আর Reusable Design থাকলে Project দীর্ঘমেয়াদে আরও শক্তিশালী হয়।

Reusability & Clean Thinking হলো এমন একটি চিন্তাভাবনা যেখানে Code, Component এবং System এমনভাবে তৈরি করা হয় যাতে সেগুলো পরিষ্কার, সহজে বোঝা যায়, রক্ষণাবেক্ষণ করা যায় এবং একাধিক Project-এ পুনঃব্যবহার করা যায়। DRY Principle, Modular Design, Reusable Components, Consistent Naming এবং Refactoring এই Mindset-এর মূল ভিত্তি। একজন দক্ষ Software Developer হওয়ার জন্য এই দক্ষতা অত্যন্ত গুরুত্বপূর্ণ।
