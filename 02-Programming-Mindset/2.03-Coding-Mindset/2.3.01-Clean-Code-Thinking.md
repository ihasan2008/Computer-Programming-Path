# > Clean Code Thinking

Clean Code Thinking হলো এমন একটি চিন্তাভাবনার পদ্ধতি, যেখানে Code শুধু **চললেই যথেষ্ট নয়**, বরং সেটি **সহজে পড়া (Readable), বোঝা (Understandable), রক্ষণাবেক্ষণযোগ্য (Maintainable), পুনঃব্যবহারযোগ্য (Reusable) এবং ভবিষ্যতে সহজে পরিবর্তনযোগ্য (Scalable)** হওয়ার লক্ষ্য রাখা হয়।

সহজ ভাষায়:

**Clean Code Thinking হলো এমনভাবে Code লেখা, যাতে অন্য একজন Programmer (বা ভবিষ্যতের তুমি নিজেও) সহজেই তা বুঝতে, ব্যবহার করতে এবং পরিবর্তন করতে পারে।**

---

## What is Clean Code?

**Clean Code** হলো এমন Code যা:

* সহজে পড়া যায়।
* সহজে বোঝা যায়।
* কম Bug থাকে।
* প্রয়োজন হলে সহজে পরিবর্তন করা যায়।
* অন্য Developer সহজে Maintain করতে পারে।

```text id="cc01"
Readable
    |
Maintainable
    |
Reusable
    |
Clean Code
```

---

## What is Clean Code Thinking?

Clean Code Thinking হলো Code লেখার আগেই এমনভাবে পরিকল্পনা করা, যাতে Code-এর গঠন (Structure), নামকরণ (Naming), Logic এবং Organization পরিষ্কার ও সহজ থাকে।

```text id="cc02"
Think
   |
Plan
   |
Write Clean Code
   |
Review
```

---

## Why is Clean Code Thinking Important?

Clean Code Thinking গুরুত্বপূর্ণ কারণ:

* Code পড়তে সহজ হয়।
* Bug কম হয়।
* Team-এর সাথে কাজ করা সহজ হয়।
* Debugging দ্রুত হয়।
* নতুন Feature যোগ করা সহজ হয়।
* Project দীর্ঘদিন Maintain করা যায়।

---

## Characteristics of Clean Code

একটি ভালো Clean Code-এর বৈশিষ্ট্য:

* **Readable** – সহজে পড়া যায়।
* **Simple** – অপ্রয়োজনীয় জটিলতা নেই।
* **Consistent** – একই Style অনুসরণ করা হয়েছে।
* **Reusable** – বারবার ব্যবহার করা যায়।
* **Maintainable** – ভবিষ্যতে পরিবর্তন করা সহজ।
* **Efficient** – অপ্রয়োজনীয় কাজ করে না।

### Principle 1: Meaningful Names

Variable, Function এবং Class-এর নাম অর্থপূর্ণ হওয়া উচিত।

❌ খারাপ:

```javascript
let x = 500;
```

✅ ভালো:

```javascript
let productPrice = 500;
```

---

### Principle 2: Keep It Simple (KISS)

**KISS = Keep It Simple, Stupid**

সম্ভব হলে সবচেয়ে সহজ সমাধান ব্যবহার করুন।

❌ অপ্রয়োজনীয় জটিলতা এড়িয়ে চলুন।

---

### Principle 3: One Function, One Job

প্রতিটি Function-এর একটি নির্দিষ্ট কাজ থাকা উচিত।

❌

```text id="cc04"
Login + Payment + Email
```

✅

```text id="cc05"
login()

processPayment()

sendEmail()
```

---

### Principle 4: DRY Principle

**DRY = Don't Repeat Yourself**

একই Code বারবার লিখবেন না।

❌

একই Logic পাঁচ জায়গায় Copy-Paste করা।

✅

একটি Function তৈরি করে বারবার ব্যবহার করা।

---

### Principle 5: Proper Formatting

Code সুন্দরভাবে Format করুন।

* Indentation ঠিক রাখুন।
* ফাঁকা Line ব্যবহার করুন।
* Consistent Style অনুসরণ করুন।

---

### Principle 6: Comments Wisely

Comment শুধুমাত্র প্রয়োজন হলে লিখুন।

❌

```javascript
// Add two numbers
let total = a + b;
```

এটি Code দেখেই বোঝা যায়।

✅

জটিল Business Logic বা বিশেষ সিদ্ধান্তের কারণ ব্যাখ্যা করতে Comment লিখুন।

---

### Principle 7: Small Functions

Function ছোট রাখুন।

```text id="cc06"
Small Function
      |
Easy to Read
      |
Easy to Test
```

---

### Principle 8: Modular Design

বড় Program-কে Module-এ ভাগ করুন।

```text id="cc07"
Project
|
├── Authentication
├── Products
├── Orders
├── Users
└── Payments
```

## Clean Code in Programming

উদাহরণ:

❌

```javascript
let a = 100;
let b = 5;
let c = a * b;
```

✅

```javascript
let productPrice = 100;
let quantity = 5;
let totalPrice = productPrice * quantity;
```

অর্থপূর্ণ নাম Code বোঝা সহজ করে।

## Clean Code vs Dirty Code

| --------------------- | ----------------------- |
| এলোমেলো               | সুসংগঠিত                |

## Famous Clean Code Principles

```text id="cc13"
KISS
|
DRY
|
YAGNI
|
SOLID
```

* **KISS (Keep It Simple, Stupid):** অপ্রয়োজনীয় জটিলতা এড়িয়ে সহজ সমাধান বেছে নাও।
* **DRY (Don't Repeat Yourself):** একই Logic বারবার লিখো না।
* **YAGNI (You Aren't Gonna Need It):** এখনই প্রয়োজন নেই এমন Feature আগে থেকে যোগ করো না।
* **SOLID:** Object-Oriented Design-এর পাঁচটি নীতি, যা বড় Software-কে নমনীয় ও Maintainable করে।

## Summary

Clean Code Thinking হলো এমনভাবে Code পরিকল্পনা ও লেখা, যাতে সেটি সহজে পড়া, বোঝা, পরীক্ষা, পরিবর্তন এবং রক্ষণাবেক্ষণ করা যায়। Meaningful Naming, Small Functions, DRY, KISS, Modular Design এবং Proper Formatting এই চিন্তাধারার গুরুত্বপূর্ণ অংশ। Programming, Web Development এবং Software Engineering-এ দীর্ঘমেয়াদে সফল হওয়ার জন্য Clean Code Thinking একটি অপরিহার্য দক্ষতা।
