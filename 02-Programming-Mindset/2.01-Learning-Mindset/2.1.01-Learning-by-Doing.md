# > Learning-by-Doing

Learning-by-Doing হলো এমন একটি শেখার পদ্ধতি, যেখানে শুধুমাত্র তত্ত্ব (Theory) পড়া নয়, বরং বাস্তবে কাজ (Practice) করে দক্ষতা অর্জন করা হয়।

সহজ ভাষায়:

**কাজ করতে করেই শেখা** হলো Learning-by-Doing। যত বেশি Practice করা হবে, তত বেশি দক্ষতা (Skill) এবং অভিজ্ঞতা (Experience) অর্জন হবে।

## What is Learning-by-Doing?

Learning-by-Doing এমন একটি শিক্ষণ পদ্ধতি, যেখানে বাস্তব কাজের মাধ্যমে জ্ঞান ও দক্ষতা অর্জন করা হয়।

```text id="ld01"
Learn
   |
Practice
   |
Experience
   |
Skill
```

এটি "Practice Makes Perfect" নীতির উপর ভিত্তি করে।

---

## Why is Learning-by-Doing Important?

Learning-by-Doing গুরুত্বপূর্ণ কারণ:

* শেখা দীর্ঘদিন মনে থাকে।
* বাস্তব সমস্যার সমাধান করতে শেখায়।
* আত্মবিশ্বাস বৃদ্ধি করে।
* দক্ষতা দ্রুত উন্নত হয়।
* ভুল থেকে শেখার সুযোগ দেয়।
* কর্মক্ষেত্রের জন্য প্রস্তুত করে।

## Theory vs Learning-by-Doing

| Theory Learning        | Learning-by-Doing    |
| ---------------------- | -------------------- |
| বই পড়ে শেখা           | কাজ করে শেখা         |
| ধারণা অর্জন            | দক্ষতা অর্জন         |
| কম বাস্তব অভিজ্ঞতা     | বেশি বাস্তব অভিজ্ঞতা |
| সহজে ভুলে যাওয়া সম্ভব | দীর্ঘদিন মনে থাকে    |
| জ্ঞান-কেন্দ্রিক        | দক্ষতা-কেন্দ্রিক     |

## Steps of Learning-by-Doing

## 1. Learn

প্রথমে বিষয়টির মৌলিক ধারণা শিখুন।

উদাহরণ:

* HTML কী?
* CSS কী?
* JavaScript কী?

---

## 2. Observe

অন্যদের কাজ দেখুন।

উদাহরণ:

* Tutorial দেখুন।
* Documentation পড়ুন।
* Source Code বিশ্লেষণ করুন।

---

## 3. Practice

নিজে হাতে কাজ করুন।

```text id="ld03"
Read
   |
Write Code
   |
Run
   |
Repeat
```

---

## 4. Make Mistakes

ভুল হওয়া শেখার স্বাভাবিক অংশ।

```text id="ld04"
Mistake
    |
Understand
    |
Fix
    |
Learn
```

---

## 5. Improve

প্রতিবার আগের চেয়ে ভালো করার চেষ্টা করুন।

* ভালো Code লিখুন।
* Speed বাড়ান।
* Accuracy উন্নত করুন।

---

## 6. Repeat

নিয়মিত অনুশীলনই দক্ষতার চাবিকাঠি।

```text id="ld05"
Practice
      |
Repeat
      |
Improve
      |
Success
```

## Common Mistakes

* শুধু Video দেখা কিন্তু Practice না করা।
* বড় Project দিয়ে শুরু করা।
* ভুল করতে ভয় পাওয়া।
* নিয়মিত অনুশীলন না করা।
* Documentation না পড়া।

## Importance of Learning-by-Doing

Learning-by-Doing:

* আধুনিক শিক্ষার অন্যতম কার্যকর পদ্ধতি।
* বাস্তব দক্ষতা (Practical Skill) গড়ে তোলে।
* সমস্যা সমাধানের ক্ষমতা বৃদ্ধি করে।
* কর্মজীবনে সফল হওয়ার ভিত্তি তৈরি করে।
* আজীবন শেখার (Lifelong Learning) অভ্যাস গড়ে তোলে।

## Summary

Learning-by-Doing হলো এমন একটি শেখার পদ্ধতি, যেখানে বাস্তব কাজ, নিয়মিত অনুশীলন এবং ভুল থেকে শিক্ষা নিয়ে দক্ষতা অর্জন করা হয়। শুধু Theory জানাই যথেষ্ট নয়—Practice, Feedback এবং ধারাবাহিক উন্নতির মাধ্যমে একজন ব্যক্তি সত্যিকারের দক্ষ হয়ে ওঠে। Programming, Office Tools, Web Development, Language Learning এবং অন্যান্য প্রায় সব ক্ষেত্রেই Learning-by-Doing সবচেয়ে কার্যকর শেখার পদ্ধতিগুলোর একটি।
