# > Error Reading Skill

Error Reading Skill হলো কোনো Error Message, Warning, Log বা System-এর দেওয়া সমস্যার বার্তা (Error Output) সঠিকভাবে পড়ে, বুঝে এবং তার কারণ নির্ণয় করার দক্ষতা।

সহজ ভাষায়:

**Error Reading Skill হলো Error দেখে ভয় না পেয়ে, সেটি মনোযোগ দিয়ে পড়ে সমস্যার আসল কারণ খুঁজে বের করার ক্ষমতা।**

---

## What is an Error?

Error হলো এমন একটি সমস্যা, যার কারণে কোনো Program, Software বা System প্রত্যাশিতভাবে কাজ করতে পারে না।

উদাহরণ:

* Programming Error
* Browser Error
* Operating System Error
* Network Error
* Database Error

```text id="ers01"
User Action
      |
System
      |
Error
      |
Message
```

---

## What is Error Reading Skill?

Error Reading Skill হলো Error Message-এর তথ্য বিশ্লেষণ করে সমস্যার উৎস (Root Cause) খুঁজে বের করার দক্ষতা।

```text id="ers02"
Read Error
     |
Understand
     |
Find Cause
     |
Fix Problem
```

---

## Why is Error Reading Skill Important?

Error Reading Skill গুরুত্বপূর্ণ কারণ:

* সমস্যা দ্রুত শনাক্ত করা যায়।
* Debugging সহজ হয়।
* Programming শেখা দ্রুত হয়।
* সময় নষ্ট কম হয়।
* Documentation বুঝতে সুবিধা হয়।
* আত্মবিশ্বাস বৃদ্ধি পায়।

## Common Types of Errors

```text id="ers03"
Errors
|
├── Syntax Error
├── Runtime Error
├── Logic Error
├── Network Error
├── File Error
├── Permission Error
└── System Error
```

---

### 1. Syntax Error

Code লেখার নিয়ম (Syntax) ভঙ্গ করলে এই Error হয়।

উদাহরণ (JavaScript):

```javascript
console.log("Hello"
```

**Error:** বন্ধ `)` অনুপস্থিত।

---

### 2. Runtime Error

Program চলার সময় (Run Time) Error ঘটে।

উদাহরণ:

* File পাওয়া যায়নি।
* Database Connection ব্যর্থ।
* Network বন্ধ।

---

### 3. Logic Error

Program চলে, কিন্তু ভুল ফলাফল দেয়।

উদাহরণ:

```javascript
let total = 5 + 5;
console.log(total * 2);
```

যদি আসল উদ্দেশ্য অন্য কিছু হয়, তাহলে Logic Error হতে পারে।

---

## 4. Permission Error

যখন User-এর প্রয়োজনীয় অনুমতি (Permission) থাকে না।

উদাহরণ:

* File Delete করতে না পারা।
* Administrator Permission প্রয়োজন।

---

## 5. File Error

যখন File খুঁজে পাওয়া যায় না বা Access করা যায় না।

উদাহরণ:

```text
File Not Found
```

---

## Parts of an Error Message

একটি Error Message সাধারণত কয়েকটি অংশ নিয়ে গঠিত।

```text id="ers04"
Error Message
|
├── Error Type
├── Description
├── File Name
├── Line Number
└── Suggestion (Sometimes)
```

## Example Error

```text
ReferenceError: username is not defined
at script.js:15
```

এখানে:

* **Error Type:** ReferenceError
* **Description:** username is not defined
* **File:** script.js
* **Line Number:** 15

## Steps to Read an Error

### 1. পুরো Error Message পড়ুন

শুধু প্রথম লাইন নয়, সম্পূর্ণ Message পড়ুন।

---

### 2. Error Type খুঁজুন

উদাহরণ:

* SyntaxError
* TypeError
* ReferenceError

---

### 3. Description পড়ুন

Error কী বলছে তা বুঝুন।

উদাহরণ:

```text
Cannot read property
```

অর্থ: এমন একটি Property ব্যবহার করা হয়েছে, যা বর্তমানে পাওয়া যাচ্ছে না।

---

### 4. File Name দেখুন

কোন File-এ সমস্যা হয়েছে তা দেখুন।

---

### 5. Line Number দেখুন

কোন Line-এ Error হয়েছে তা পরীক্ষা করুন।

---

### 6. Documentation দেখুন

যদি Error বুঝতে সমস্যা হয়, তাহলে Official Documentation বা নির্ভরযোগ্য উৎস দেখুন।

---

### 7. Fix & Test

সমস্যা ঠিক করে আবার Program চালান।

---

## Error Reading in Programming

উদাহরণ:

```javascript
let name = Hasan;
```

Error:

```text
ReferenceError: Hasan is not defined
```

কারণ:

`Hasan`-কে String হিসেবে লিখতে Quotes (`"Hasan"` বা `'Hasan'`) ব্যবহার করা হয়নি।

সঠিক Code:

```javascript
let name = "Hasan";
```

## Common Mistakes

* Error Message না পড়ে অনুমান করা।
* শুধু Google Search করে Copy-Paste Solution ব্যবহার করা।
* Line Number উপেক্ষা করা।
* একই Error বারবার করা।
* Error-এর Root Cause না বুঝে সাময়িক সমাধান করা।
