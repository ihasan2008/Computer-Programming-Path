# > Keyword Understanding

Keyword Understanding হলো কোনো বিষয়, বাক্য, প্রশ্ন, Document, Programming Language বা Search Query-এর গুরুত্বপূর্ণ শব্দ (Keyword) সঠিকভাবে শনাক্ত (Identify), অর্থ বোঝা (Understand) এবং প্রেক্ষাপট (Context) অনুযায়ী ব্যবহার করার দক্ষতা।

সহজ ভাষায়:

**Keyword Understanding হলো গুরুত্বপূর্ণ শব্দগুলো চিনে তাদের সঠিক অর্থ ও ব্যবহার বুঝতে পারার ক্ষমতা।**

## What is a Keyword?

Keyword হলো এমন একটি গুরুত্বপূর্ণ শব্দ বা শব্দগুচ্ছ (Phrase), যা কোনো বিষয়ের মূল ধারণা বা প্রধান তথ্য প্রকাশ করে।

উদাহরণ:

বাক্য:

> **"HTML is used to create web pages."**

এখানে Keyword হলো:

* HTML
* Create
* Web Pages

```text id="ku01"
    |
Keywords
    |
Main Idea
```

## Why is Keyword Understanding Important?

Keyword Understanding গুরুত্বপূর্ণ কারণ:

* দ্রুত মূল বিষয় বোঝা যায়।
* Search আরও কার্যকর হয়।
* Documentation পড়া সহজ হয়।
* Programming শেখা সহজ হয়।
* Communication উন্নত হয়।
* Problem Solving দক্ষতা বৃদ্ধি পায়।

### 2. Technical Keywords

---

### 3. Search Keywords

Search Engine-এ তথ্য খোঁজার জন্য ব্যবহৃত শব্দ।

উদাহরণ:

```text id="ku04"
"Learn HTML"

"Best JavaScript Course"

"Python Tutorial"
```

সঠিক Keyword ব্যবহার করলে আরও ভালো Search Result পাওয়া যায়।

---

### 4. Programming Keywords

Programming Language-এর Reserved Word-কে Keyword বলা হয়।

উদাহরণ (JavaScript):

```javascript
if
else
for
while
function
return
const
let
class
```

এই শব্দগুলোর নির্দিষ্ট অর্থ রয়েছে এবং এগুলো Variable Name হিসেবে ব্যবহার করা যায় না।

---

### 5. Academic Keywords

শিক্ষা ও গবেষণায় ব্যবহৃত গুরুত্বপূর্ণ শব্দ।

* Analysis
* Conclusion
* Evidence
* Hypothesis
* Research

## Keyword Understanding in Programming

Programming শেখার সময় Keyword বোঝা খুব গুরুত্বপূর্ণ।

উদাহরণ:

```javascript
if (age >= 18) {
   console.log("Adult");
}
```

এখানে Keyword:

* if
* console
* log

এগুলোর কাজ বুঝলে Code সহজে বোঝা যায়।

---

## Keyword Understanding in Search

উদাহরণ:

তুমি যদি Search করো:

```text id="ku07"
HTML
```

তাহলে অনেক ফলাফল আসবে।

কিন্তু যদি Search করো:

```text id="ku08"
HTML Forms Tutorial
```

তাহলে আরও নির্দিষ্ট ফলাফল পাওয়া যাবে।

এটি Keyword নির্বাচন করার গুরুত্ব বোঝায়।

## Keyword Understanding in Reading

ধরো একটি বাক্য:

> "Cloud Storage allows users to store data online securely."

Keyword:

* Cloud Storage
* Store
* Data
* Online
* Securely

এই Keyword বুঝলে পুরো বাক্যের অর্থ সহজে বোঝা যায়।

## How to Improve Keyword Understanding

* প্রতিদিন নতুন Vocabulary শিখুন।
* Dictionary ব্যবহার করুন।
* Documentation পড়ুন।
* Technical Article পড়ুন।
* গুরুত্বপূর্ণ শব্দ Highlight করুন।
* নিজের ভাষায় Keyword-এর অর্থ লিখুন।
* একই Keyword বিভিন্ন Context-এ ব্যবহার করুন।

---

## Common Mistakes

* Keyword-এর অর্থ না বুঝে মুখস্থ করা।
* Context না দেখে অর্থ নির্ধারণ করা।
* একই Keyword সব জায়গায় একই অর্থ ধরে নেওয়া।
* Technical Keyword উপেক্ষা করা।
