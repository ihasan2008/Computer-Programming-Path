# > (1) 📝 Code Editor

## Visual Studio Code (VS Code)

**VS Code** হলো এমন একটি software যেখানে programmer code লেখে, edit করে এবং project-এর বিভিন্ন file manage করে।

সহজভাবে:

> **VS Code = Code লেখার খাতা + Coding-এর workspace**

### কী কী করা যায়?

VS Code দিয়ে:

* নতুন code file তৈরি করা যায়
* Code লেখা যায়
* Code edit করা যায়
* একসাথে অনেক file খোলা যায়
* Project-এর folder manage করা যায়
* Code-এর error দেখতে সাহায্য পাওয়া যায়
* Terminal ব্যবহার করা যায়
* Git ব্যবহার করা যায়
* Extension install করা যায়
* Debugging করা যায়

### উদাহরণ

তুমি যদি HTML শেখো, VS Code-এ:

```text
index.html
```

file তৈরি করে লিখতে পারো:

```html
<h1>Hello World</h1>
```

### কেন গুরুত্বপূর্ণ?

Programming শেখার সময় সবচেয়ে বেশি সময় তুমি **code লেখার জায়গায়** কাটাবে। তাই ভালো Code Editor জানা খুব গুরুত্বপূর্ণ।

### Recommended

**VS Code ⭐⭐⭐⭐⭐**

# > (2) ⌨️ Terminal

**Terminal** হলো এমন একটি interface যেখানে graphical button ব্যবহার না করে **command লিখে computer-কে কাজ করানো যায়।**

সহজভাবে:

> **Terminal = Computer-কে command দিয়ে কাজ করানোর জায়গা**

### উদাহরণ

```bash
mkdir my-project
```

এই command দিয়ে নতুন folder তৈরি করা যায়।

আর:

```bash
cd my-project
```

দিয়ে সেই folder-এর ভিতরে যাওয়া যায়।

### Terminal দিয়ে কী করা যায়?

* Folder তৈরি
* Folder পরিবর্তন
* File manage
* Program run
* Git command চালানো
* Package install
* Development server চালানো

### Windows-এ জনপ্রিয় Terminal

```text
Windows Terminal
PowerShell
Command Prompt
Git Bash
```

### Beginner-এর জন্য

প্রথমে **Windows Terminal + PowerShell** সম্পর্কে basic ধারণা নিলেই ভালো।

### কেন গুরুত্বপূর্ণ?

Professional programming-এ অনেক কাজ command line দিয়ে করা হয়। তাই Terminal ব্যবহার জানা একজন programmer-এর basic skill।

**Priority: ⭐⭐⭐⭐⭐**

# > (3) 🔀 Git

**Git** হলো একটি **Version Control System**।

এটি তোমার code-এর বিভিন্ন পরিবর্তনের history সংরক্ষণ করে।

সহজভাবে:

> **Git = Code-এর পরিবর্তনের ইতিহাস রাখার system**

### ধরো

আজ তুমি project বানালে:

```text
Version 1
```

কাল কিছু পরিবর্তন করলে:

```text
Version 2
```

পরের দিন ভুল করে code নষ্ট করলে:

```text
Version 3 ❌
```

Git ব্যবহার করলে আগের version-এর history রাখা থাকতে পারে।

### Git কী কী করে?

* Code-এর change track করে
* Commit তৈরি করে
* History রাখে
* পুরোনো অবস্থায় ফিরে যেতে সাহায্য করে
* Branch তৈরি করতে দেয়
* বিভিন্ন code version manage করতে সাহায্য করে

### Basic Git command

```bash
git status
```

বর্তমান project-এর অবস্থা দেখায়।

```bash
git add .
```

পরিবর্তনগুলো commit-এর জন্য প্রস্তুত করে।

```bash
git commit -m "Initial commit"
```

পরিবর্তনের একটি version/history তৈরি করে।

### কেন গুরুত্বপূর্ণ?

একজন programmer-এর project বড় হওয়ার সাথে সাথে code-এর পরিবর্তন track করা খুব প্রয়োজনীয় হয়ে যায়।

**Priority: ⭐⭐⭐⭐⭐**

# > (6) ⚙️ Compiler / Interpreter / Runtime

Programming language-এর code computer বুঝে execute করার জন্য বিভিন্ন ধরনের software প্রয়োজন হয়।

এগুলোকে broadly **Compiler, Interpreter এবং Runtime** বলা হয়।

---

## 6.1 Compiler

Compiler source code-কে অন্য একটি executable বা lower-level form-এ রূপান্তর করে।

সহজভাবে:

```text
Source Code
     ↓
Compiler
     ↓
Executable / Machine Code
     ↓
Computer
```

### উদাহরণ

C/C++ programming-এর ক্ষেত্রে:

```text
C/C++ Code
     ↓
GCC / Clang / MSVC
     ↓
Program
```

---

## 6.2 Interpreter

Interpreter সাধারণত program-এর source code execute করার সময় সেটিকে process করে।

উদাহরণ:

```text
Python Code
     ↓
Python Interpreter
     ↓
Output
```

Python চালানোর জন্য Python interpreter প্রয়োজন।

---

## 6.3 Runtime

Runtime হলো এমন environment যেখানে program execute হয়।

উদাহরণ:

**Node.js** হলো JavaScript runtime।

Browser-এর বাইরে JavaScript চালাতে Node.js ব্যবহার করা যায়।

```bash
node app.js
```

### কেন গুরুত্বপূর্ণ?

Programming language অনুযায়ী code চালানোর জন্য সঠিক compiler, interpreter বা runtime প্রয়োজন।

**Priority: ⭐⭐⭐⭐⭐**

> তুমি যে language শিখবে, সেই language অনুযায়ী tool install করবে। সব compiler/interpreter একসাথে install করার প্রয়োজন নেই।

# > (7) 🐞 Debugger

**Debugger** হলো program-এর ভিতরের সমস্যা খুঁজে বের করার tool।

সহজভাবে:

> **Debugger = Code-এর কোথায় এবং কেন সমস্যা হচ্ছে তা খুঁজে বের করার tool**

### ধরো

তোমার code:

```javascript
let age = 18;

if (age > 20) {
    console.log("Adult");
}
```

কিন্তু তুমি expected result পাচ্ছ না।

Debugger দিয়ে program-এর execution step-by-step দেখা যায়।

### গুরুত্বপূর্ণ Debugging Concepts

```text
Breakpoint
Step Over
Step Into
Variables
Call Stack
Watch
```

### Breakpoint কী?

Code-এর একটি নির্দিষ্ট জায়গায় program থামিয়ে দেওয়া।

তারপর তুমি দেখতে পারবে:

* Variable-এর value কী
* কোন line execute হয়েছে
* এরপর কী হবে

### কেন গুরুত্বপূর্ণ?

Programming-এ **error এবং bug আসবেই**।

তাই শুধু code লেখা নয়, **debugging শেখাও programming-এর গুরুত্বপূর্ণ অংশ।**

**Priority: ⭐⭐⭐⭐⭐**

# > (12) 🔗 PATH / Environment Variables

Computer-এ installed programming tools যেন Terminal থেকে ব্যবহার করা যায়, তার জন্য **PATH** গুরুত্বপূর্ণ।

### উদাহরণ

যদি Python PATH-এ properly configured থাকে, তাহলে Terminal থেকে:

```bash
python --version
```

চালালে Python-এর version দেখা যাবে।

### PATH কী?

PATH হলো এমন একটি environment variable যেখানে computer executable program খুঁজে পাওয়ার জন্য বিভিন্ন location রাখে।

### কেন গুরুত্বপূর্ণ?

Compiler, interpreter, Git, Node.js ইত্যাদি Terminal থেকে command হিসেবে ব্যবহার করার সময় PATH-এর ধারণা কাজে লাগে।

**Priority: ⭐⭐⭐**

> Beginner হিসেবে basic ধারণা যথেষ্ট; শুরুতেই advanced environment configuration শেখার প্রয়োজন নেই।

# 🧠 Final Concept

Coding করার সময় সাধারণত workflow হবে:

```text
Computer
   ↓
File / Folder
   ↓
VS Code
   ↓
Write Code
   ↓
Compiler / Interpreter
   ↓
Run Program
   ↓
Error?
   ↓
Debugger
   ↓
Fix Code
   ↓
Git
   ↓
Save Version
```

আর Web Development হলে:

```text
Code
 ↓
VS Code
 ↓
Browser
 ↓
DevTools
 ↓
Debug
 ↓
Fix
 ↓
Git
```

> **প্রথমে tool-এর নাম মুখস্থ করার চেয়ে প্রতিটি tool কেন ব্যবহার করা হয় সেটা বুঝো। তারপর বাস্তবে ব্যবহার করতে করতে tool শেখো।**
