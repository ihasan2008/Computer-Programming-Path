# > Syntax Basics

## 1. Syntax কী?

**Syntax** হলো কোনো Programming Language-এ code লেখার নির্দিষ্ট **নিয়ম ও structure**।

যেমন আমরা মানুষের ভাষায় grammar মেনে বাক্য লিখি, programming language-এও নির্দিষ্ট rules মেনে code লিখতে হয়।

### সহজভাবে

> **Syntax = Code লেখার Grammar**

উদাহরণ:

```javascript
let name = "Hasan";
```

এখানে `let`, variable name, `=`, value এবং `;`—সবকিছু নির্দিষ্ট syntax অনুসরণ করছে।

---

## 2. Syntax কেন গুরুত্বপূর্ণ?

Programming Language computer-এর জন্য নির্দিষ্ট rules ব্যবহার করে।

Syntax ভুল হলে সাধারণত:

```text
Syntax Error
```

দেখাতে পারে।

### Syntax শেখার মাধ্যমে তুমি বুঝবে:

* Code কীভাবে লিখতে হয়
* Statement কী
* Variable কীভাবে declare করতে হয়
* Operator কোথায় ব্যবহার করতে হয়
* `{ }`, `( )`, `[ ]` কোথায় ব্যবহার করতে হয়
* String কীভাবে লিখতে হয়
* Code block কীভাবে তৈরি হয়
* Indentation কীভাবে ব্যবহার করতে হয়
* Comment কীভাবে লিখতে হয়
* Error দেখে ভুল খুঁজে বের করতে হয়

## 4. Keywords

**Keyword** হলো programming language-এর reserved word, যার নির্দিষ্ট অর্থ রয়েছে।

JavaScript:

```javascript
let
const
if
else
for
while
function
return
```

Python:

```python
if
else
for
while
def
return
import
```

Keyword সাধারণত variable বা function-এর নাম হিসেবে ব্যবহার করা যায় না।

---

## 5. Identifiers

**Identifier** হলো programmer-এর দেওয়া নাম।

যেমন:

```javascript
let name = "Hasan";
let age = 18;
```

এখানে:

```text
name → Identifier
age  → Identifier
```

Identifier হতে পারে:

* Variable name
* Function name
* Class name
* Object name

### ভালো Naming

```javascript
userName
totalPrice
studentAge
```

### খারাপ Naming

```javascript
x
a1
abc
```

সবসময় সম্ভব হলে meaningful name ব্যবহার করা ভালো।

## 6. Literals / Values

Code-এর মধ্যে সরাসরি লেখা actual data-কে **Literal** বলা হয়।

উদাহরণ:

```javascript
10
25.5
"Hasan"
true
false
```

এগুলো বিভিন্ন ধরনের value।

```text
10       → Number
25.5     → Number
"Hasan"  → String
true     → Boolean
false    → Boolean
```

---

## 7. Variables

Variable হলো data রাখার জন্য একটি named storage/reference।

JavaScript:

```javascript
let age = 18;
```

এখানে:

```text
let   → Keyword
age   → Identifier
=     → Assignment Operator
18    → Value
;     → Statement Terminator
```

এটাই syntax-এর বিভিন্ন অংশ কীভাবে একসাথে কাজ করে তার একটি basic example।

---

## 8. Statements

**Statement** হলো programming language-এর একটি complete instruction।

উদাহরণ:

```javascript
let age = 18;
```

আরেকটি:

```javascript
console.log(age);
```

প্রতিটি statement computer-কে একটি নির্দিষ্ট কাজ করতে বলে।

একটি program সাধারণত অনেকগুলো statement-এর সমন্বয়ে তৈরি হয়।

```text
Statement
   ↓
Statement
   ↓
Statement
   ↓
Statement
```

---

## 9. Expressions

**Expression** হলো এমন code যা সাধারণত একটি value produce করে।

উদাহরণ:

```javascript
10 + 20
```

Result:

```text
30
```

আরেকটি:

```javascript
age + 5
```

যদি:

```javascript
age = 18
```

তাহলে result:

```text
23
```

### Expression বনাম Statement

| বিষয়    | Expression     | Statement            |
| ------- | -------------- | -------------------- |
| কাজ     | Value তৈরি করে | Instruction দেয়      |
| Example | `10 + 20`      | `let x = 10;`        |
| Result  | সাধারণত value  | একটি কাজ সম্পন্ন করে |

## 11. Delimiters

কিছু symbol code-এর বিভিন্ন অংশ আলাদা বা group করতে ব্যবহৃত হয়।

### Parentheses

```javascript
()
```

```javascript

```

### Curly Braces

```javascript
{}
```

Code block তৈরি করতে ব্যবহৃত হয়।

### Square Brackets

## 12. Semicolon

কিছু language-এ statement শেষ করার জন্য `;` ব্যবহার করা হয়।

JavaScript:

```javascript
let name = "Hasan";
let age = 18;
```

এখানে `;` statement-এর শেষ নির্দেশ করে।

তবে সব programming language-এ semicolon বাধ্যতামূলক নয়।

উদাহরণ:

```python
name = "Hasan"
age = 18
```

Python-এ সাধারণত `;` প্রয়োজন হয় না।

## 13. Curly Braces `{ }`

Curly braces অনেক language-এ **code block** তৈরি করতে ব্যবহৃত হয়।

JavaScript:

```javascript

    console.log("Adult");

```

এখানে:

```text

   Code Block
}
```

এর মধ্যে থাকা code নির্দিষ্ট condition-এর অংশ।

## 17. Comments

Comment হলো programmer-এর জন্য লেখা explanation, যা সাধারণত program execution-এর অংশ নয়।

JavaScript:

```javascript
// This is a comment
```

Multi-line:

```javascript
/*
   This is a
   multi-line comment
*/
```

Comments ব্যবহার করা হয়:

* Code explain করতে
* Important information রাখতে
* Temporary code disable করতে
* Future reference-এর জন্য

## 18. Indentation

**Indentation** হলো code-এর alignment/spacing।

উদাহরণ:

```javascript
if (age >= 18) {
    console.log("Adult");
}
```

এখানে `console.log()` indentation করা হয়েছে।

Python-এ indentation syntax-এর অংশও হতে পারে:

```python
if age >= 18:
    print("Adult")
```

তাই programming language অনুযায়ী indentation-এর গুরুত্ব আলাদা হতে পারে।

---

## 19. Case Sensitivity

অনেক programming language **case-sensitive**।

যেমন JavaScript:

```javascript
let name = "Hasan";
```

এবং:

```javascript
let Name = "Hasan";
```

এগুলো একই identifier নয়।

```text
name ≠ Name
```

তাই uppercase এবং lowercase-এর পার্থক্য বুঝতে হবে।

## 20. Basic Syntax Structure

একটি সাধারণ code structure:

```text
Keyword
   ↓
Identifier
   ↓
Operator
   ↓
Value
   ↓
Terminator
```

Example:

```javascript
let age = 18;
```

Breakdown:

```text
let  → Keyword
age  → Identifier
=    → Operator
18   → Value
;    → Terminator
```

## 21. Code Block Structure

অনেক programming language-এ code block তৈরি করা হয়।

উদাহরণ:

```javascript
if (condition) {
    statement;
    statement;
}
```

Structure:

```text
if
 ↓
condition
 ↓
{
   code
   code
}
```

এটি বুঝতে পারলে পরে `if-else`, loops, functions ইত্যাদি শেখা সহজ হয়।

> **Syntax changes, Programming Logic remains transferable.**

## 25. Syntax vs Logic

এটি খুব গুরুত্বপূর্ণ।

### Syntax

Code কীভাবে লিখতে হবে।

### Logic

Code কীভাবে চিন্তা করে কাজ করবে।

উদাহরণ:

```text
User age >= 18
        ↓
    Adult
```

এটা হলো **Logic**।

কিন্তু JavaScript-এ:

```javascript
if (age >= 18) {
    console.log("Adult");
}
```

এটা হলো সেই logic-এর **Syntax**।

### মনে রাখবে

```text
Syntax = How to write
Logic  = How to think
```

একজন ভালো programmer শুধু syntax মুখস্থ করে না—সে logic বুঝে।

### সবচেয়ে গুরুত্বপূর্ণ কথা

> **Syntax শেখা মানে শুধু code-এর rules মুখস্থ করা নয়; code-এর structure বুঝতে শেখা।**

```text
Syntax → How to Write
Logic  → How to Think
Problem Solving → How to Solve
```

## 🔑 Memory Formula

**K-I-V-O-S-B**

```text
K → Keywords
I → Identifiers
V → Values
O → Operators
S → Statements
B → Blocks
```

আর Programming শেখার সময় মনে রাখো:

> **Understand the Syntax → Understand the Structure → Understand the Logic → Build → Test → Debug**
