# 01 - Boolean কি?

Boolean variable (বুলিয়ান ভেরিয়েবল বা বুলিয়ান চলক) হলো এমন একটি বিশেষ ধরনের ভেরিয়েবল, যা মাত্র দুটি সম্ভাব্য মান ধারণ করতে পারে: True (সত্য) অথবা False (মিথ্যা)। এছাড়া এদেরকে ১ ও ০, অথবা হ্যাঁ/না (Yes/No), কিংবা চালু/বন্ধ (On/Off) হিসেবেও প্রকাশ করা হয়।


# 02 - Boolean কীভাবে কাজ করে?

Boolean (বুলিয়ান) ভ্যারিয়েবল মূলত কম্পিউটার প্রোগ্রামিংয়ে কোনো কিছুর সত্যতা (Truth value) যাচাই করার জন্য কাজ করে। এর কেবল দুটি সম্ভাব্য মান (value) থাকতে পারে: True (সত্য) অথবা False (মিথ্যা)।

* *সহজ কথায়,* এটি একটি ইলেকট্রনিক সুইচের মতো—হয় অন (True) না হয় অফ (False)। কম্পিউটারের বাইনারি সিস্টেমে True-কে 1 এবং False-কে 0 দিয়ে প্রকাশ করা হয়।

**প্রোগ্রামিংয়ে বুলিয়ান ভ্যারিয়েবল সাধারণত কোনো শর্ত বা কন্ডিশন (Condition) চেক করার জন্য ব্যবহৃত হয়। নিচে একটি বাস্তব উদাহরণ দিয়ে বিষয়টি বোঝানো হলো:**

**ধরে নিন, আপনি একটি ওয়েবসাইটে লগইন করতে চাচ্ছেন। সেখানে ব্যাকএন্ডে একটি বুলিয়ান ভ্যারিয়েবল থাকতে পারে:**

* • is_logged_in = True (তার মানে আপনি লগইন অবস্থায় আছেন এবং প্রোফাইল দেখতে পারবেন)

* • is_logged_in = False (তার মানে আপনি লগইন করেননি এবং আপনাকে লগইন পেজে নিয়ে যাওয়া হবে)
