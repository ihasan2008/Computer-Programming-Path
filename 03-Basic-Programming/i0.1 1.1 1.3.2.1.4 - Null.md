# 01 - Null কি?

প্রোগ্রামিং এবং ডেটাবেজে Null বা Null variable হলো এমন একটি বিশেষ মান (Value) বা অবস্থা, যা নির্দেশ করে যে কোনো ভেরিয়েবল বা মেমোরি লোকেশনে কোনো নির্দিষ্ট মান নেই বা সেটি খালি।

**সহজ কথায় কিছু গুরুত্বপূর্ণ বিষয়:**

* *শূন্য (0) বা ফাঁকা স্ট্রিং নয়:* 0 বা একটি ফাঁকা টেক্সট ("") মানে কিন্তু Null নয়। যেমন: কারও কাছে কয়টি বই আছে—তার উত্তর 0 হওয়া মানে তার কাছে কোনো বই নেই (সংখ্যাটি জানা আছে), আর Null হওয়া মানে তার কাছে কয়টি বই আছে তা এখনো জানা বা নির্ধারণ করা যায়নি।

* *মেমোরিতে অবস্থান:* প্রোগ্রামিং ভাষায় (যেমন Java বা C) কোনো রেফারেন্স ভেরিয়েবলে Null সেট করার অর্থ হলো—ভেরিয়েবলটি বর্তমানে মেমোরির কোনো অবজেক্ট বা ঠিকানার দিকে নির্দেশ করছে না।

* *ডেটাবেজে ব্যবহার:* SQL-এ কোনো টেবিলের নির্দিষ্ট কোনো ফিল্ডের তথ্য অনুপস্থিত বা প্রযোজ্য নয় বোঝাতে NULL ব্যবহার করা হয়।

* *Null Pointer Exception:* কোনো ভেরিয়েবল যখন Null অবস্থায় থাকে এবং সেটিকে কোনো বৈধ মান মনে করে অপারেশন চালাতে গেলে প্রোগ্রাম ক্র্যাশ করতে পারে (যাকে অনেক ভাষায় NullPointerException বলা হয়)।


# 02 - Null কেন ব্যবহার করা হয়?

Null variable মূলত কোনো ভ্যারিয়েবলে কোনো ভ্যালু বা ডেটা (Value/Data) নেই—এটি নির্দেশ করার জন্য ব্যবহার করা হয়।

*সহজ কথায়,* একটি ভ্যারিয়েবল তৈরি করা হয়েছে কিন্তু তার ভেতর এখনো কোনো নির্দিষ্ট তথ্য রাখা হয়নি, এই ফাঁকা অবস্থাটি বোঝাতেই null ব্যবহার করা হয়।

**এটি ব্যবহারের প্রধান কারণগুলো নিচে দেওয়া হলো:**

* • খালি বা অনুপস্থিত অবস্থা বোঝাতে: ধরুন আপনি একটি অনলাইন ফর্ম তৈরি করছেন যেখানে "Middle Name" বা মাঝের নাম দেওয়ার জায়গা আছে। যদি কারো মাঝের নাম না থাকে, তবে সেই ভ্যারিয়েবলের মান null রাখা হয়।

* • ভ্যারিয়েবল ইনিশিয়ালাইজ (Initialize) করতে: অনেক সময় প্রোগ্রামিংয়ে একটি ভ্যারিয়েবল আগে থেকেই তৈরি করে রাখা হয়, কিন্তু তার আসল মান পরে (যেমন: ইউজারের ইনপুট বা ডাটাবেজ থেকে) আসবে। শুরুতে সেটিকে খালি রাখার জন্য null দিয়ে সেট করা হয়।

* • ডিফল্ট স্টেট (Default State) হিসেবে: কোনো অবজেক্ট বা ডেটা এখনো লোড হয়নি বা তৈরি হয়নি তা নিশ্চিত করতে ডিফল্ট মান হিসেবে এটি ব্যবহৃত হয়।

* • মেমোরি খালি করতে: কোনো বড় অবজেক্ট বা ডেটার কাজ শেষ হয়ে গেলে সেটির ভ্যারিয়েবলকে null করে দেওয়া হয়, যাতে মেমোরি খালি (Garbage Collection) হতে সুবিধা হয়।


# 03 - Null কিভাবে কাজ করে?

Null variable (বা নাল ভেরিয়েবল) প্রোগ্রামিংয়ের একটি বিশেষ ধারণা, যা মূলত বোঝায় যে ভেরিয়েবলটির কোনো মান (Value) নেই বা এটি সম্পূর্ণ খালি।

* *সহজ কথায়,* আপনি যখন একটি ভেরিয়েবল তৈরি করেন কিন্তু তার মধ্যে কোনো ডাটা বা অবজেক্ট রাখেন না, তখন সেটির মান হয় null। এটি কোনো শূন্য (0) বা খালি স্পেস (" ") নয়, বরং ডাটার অনুপস্থিতি।
