# > Keywords & Identifiers

## 1. Keywords & Identifiers কী?

Programming Language-এ code লেখার সময় কিছু শব্দ language নিজেই নির্দিষ্ট কাজের জন্য reserve করে রাখে। এগুলো হলো **Keywords**।

আর programmer নিজে Variable, Function, Class ইত্যাদির জন্য যে নাম দেয়, সেগুলো হলো **Identifiers**।

সহজভাবে:

```text
Keyword     → Language-এর reserved name
Identifier  → Programmer-এর দেওয়া name
```

---

## 2. Keyword কী?

**Keyword** হলো Programming Language-এর এমন একটি **reserved word**, যার একটি নির্দিষ্ট অর্থ এবং কাজ রয়েছে।

উদাহরণ JavaScript:

```javascript
let
const
if
else
for
while
function
return
class
new
```

এগুলো language-এর নিজস্ব keyword।

---

## 3. Keyword কেন গুরুত্বপূর্ণ?

Programming Language-এর structure এবং behavior তৈরি করতে keywords ব্যবহার করা হয়।

যেমন:

```javascript
if (age >= 18) {
    console.log("Adult");
}
```

এখানে:

```text
if → Keyword
```

`if` language-কে বলে যে একটি **condition check** করতে হবে।

আর:

```javascript
return value;
```

এখানে:

```text
return → Keyword
```

function থেকে value ফেরত দেওয়ার নির্দেশ দেয়।

## 5. Keyword কি Variable Name হতে পারে?

সাধারণভাবে **না**।

ভুল:

```javascript
let if = 10;
```

কারণ `if` একটি reserved keyword।

সঠিক:

```javascript
let age = 10;
```

এখানে:

```text
age → Identifier
```

---

## 6. Identifier কী?

**Identifier** হলো programmer-এর দেওয়া একটি নাম, যার মাধ্যমে program-এর বিভিন্ন entity-কে identify করা হয়।

যেমন:

```javascript
let name = "Hasan";
let age = 18;
```

এখানে:

```text
name → Identifier
age  → Identifier
```

Function:

```javascript
function calculateTotal() {
}
```

এখানে:

```text
calculateTotal → Identifier
```

---

## 7. Identifier কোথায় ব্যবহার হয়?

Identifier বিভিন্ন জায়গায় ব্যবহার করা যায়।

```text
Identifier
│
├── Variable Name
├── Constant Name
├── Function Name
├── Class Name
├── Object Name
├── Parameter Name
└── অন্যান্য program entity-এর name
```

উদাহরণ:

```javascript
let userName = "Hasan";

function greetUser() {
}

class Student {
}
```

এখানে:

```text
userName   → Identifier
greetUser  → Identifier
Student    → Identifier
```

---

## 8. Identifier Naming Rules

Programming Language অনুযায়ী কিছু পার্থক্য থাকলেও সাধারণভাবে Identifier-এর কিছু basic rule আছে।

### Rule 1 — Letter দিয়ে শুরু করা যায়

```javascript
let name = "Hasan";
let age = 18;
```

---

### Rule 2 — `_` দিয়ে শুরু করা যায়

অনেক language-এ:

```javascript
let _name = "Hasan";
```

valid হতে পারে।

---

### Rule 3 — `$` কিছু language-এ ব্যবহার করা যায়

JavaScript-এ:

```javascript
let $price = 500;
```

valid identifier হতে পারে।

তবে `$` সব Programming Language-এ valid নয়।

---

### Rule 4 — Number দিয়ে শুরু করা যায় না

ভুল:

```javascript
let 1name = "Hasan";
```

সঠিক:

```javascript
let name1 = "Hasan";
```

অর্থাৎ:

```text
1name ❌
name1 ✅
```

---

### Rule 5 — Space ব্যবহার করা যায় না

ভুল:

```javascript
let user name = "Hasan";
```

সঠিক:

```javascript
let userName = "Hasan";
```

অথবা:

```javascript
let user_name = "Hasan";
```

---

### Rule 6 — Keyword ব্যবহার করা যাবে না

ভুল:

```javascript
let class = "Programming";
```

কারণ `class` একটি keyword।

সঠিক:

```javascript
let className = "Programming";
```

---

## 9. Case Sensitivity

অনেক Programming Language **case-sensitive**।

যেমন:

```javascript
let name = "Hasan";
let Name = "Rakib";
```

এখানে:

```text
name ≠ Name
```

আবার:

```text
age ≠ Age
```

তাই uppercase এবং lowercase-এর পার্থক্য গুরুত্বপূর্ণ।

## 10. Meaningful Identifier

Identifier এমন হওয়া উচিত যাতে নাম দেখেই বোঝা যায় এটি কী represent করছে।

### ভালো:

```javascript
let studentName;
let totalPrice;
let userAge;
let productQuantity;
```

### দুর্বল:

```javascript
let x;
let a;
let abc;
let data1;
```

ছোট নাম সবসময় ভুল নয়। কিন্তু বড় program-এ meaningful naming code বুঝতে অনেক সহজ করে।

## 11. Naming Convention

Programming-এ Identifier লেখার বিভিন্ন style আছে।

### camelCase

JavaScript-এ খুব common:

```javascript
let firstName;
let totalPrice;
let userAge;
```

---

### snake_case

Python-এ খুব common:

```python
first_name
total_price
user_age
```

---

### PascalCase

সাধারণত Class-এর ক্ষেত্রে ব্যবহার করা হয়:

```javascript
class UserProfile {
}
```

---

### UPPER_CASE

Constant বা configuration-এর ক্ষেত্রে অনেক project-এ ব্যবহার করা হয়:

```javascript
const MAX_USERS = 100;
```

## 20. তবে ছোট Identifier কখন ব্যবহার করা যায়?

সবসময় বড় নাম প্রয়োজন নেই।

Loop-এর ক্ষেত্রে:

```javascript
for (let i = 0; i < 10; i++) {
}
```

এখানে `i` একটি সাধারণ convention।

Function parameter-এর ক্ষেত্রেও context পরিষ্কার হলে ছোট নাম ব্যবহার করা যেতে পারে:

```javascript
function add(a, b) {
    return a + b;
}
```

কিন্তু complex logic হলে meaningful name বেশি ভালো।

```javascript

```

এখানে:

```text
userName ≠ username
```

---

### Mistake 5 — Meaningless Name

```javascript
let a = 500;
let b = 20;

```

Code ছোট হলেও বুঝতে অসুবিধা হতে পারে।

Better:

```javascript
let productPrice = 500;
let discount = 20;
let finalPrice = productPrice - discount;
```
