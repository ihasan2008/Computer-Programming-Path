# > i0.1 1.1 1.3.2.1 - Variable & Data Types

> Programming-এ Variable (ভ্যারিয়েবল) ও Data Type (ডেটা টাইপ) হলো একদম মৌলিক দুটি বিষয়। এগুলো বুঝলে তুমি সহজে বুঝতে পারবে প্রোগ্রাম কীভাবে ডেটা সংরক্ষণ করে এবং সেই ডেটা নিয়ে কাজ করে।

## 1. Variable কী?

> Variable হলো একটি নামযুক্ত স্থান, যেখানে প্রোগ্রাম চলার সময় কোনো ডেটা রাখা যায় এবং প্রয়োজনে সেই ডেটা পরিবর্তন করা যায়।

JavaScript-এ উদাহরণ:
```
let age = 18;
console.log(age);
```

## 2. Data Type কী?

> Data Type হলো ডেটা কোন ধরনের, তা নির্দেশ করে।
> যেমন, কোনো ডেটা সংখ্যা, লেখা, সত্য-মিথ্যা, নাকি একাধিক মানের সংগ্রহ—তা বোঝার জন্য Data Type ব্যবহার করা হয়।
